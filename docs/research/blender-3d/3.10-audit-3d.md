## 1. "Blurry" — cause

| Checked | Result | Verdict |
|---|---|---|
| Canvas DPR | R3F default `dpr=[1,2]`; measured buffer 541×770 for CSS 433×616 at `devicePixelRatio` 1.25 → correct | **not the cause** |
| Antialias | context `antialias: true`, `SAMPLES = 4` | **not the cause** |
| Texture filtering | there are **no textures** at all (0 in 20 GLBs; walls/floor = flat colours) | n/a |
| Materials | **all 20 GLBs use `KHR_materials_unlit`** → GLTFLoader builds `MeshBasicMaterial` → no light, no shade, no shadow on furniture | **main cause** |

So "blurry" is really *flat*: furniture is drawn in one solid colour per material with no
shading, so edges and volumes melt into each other and the eye reads it as soft/blurry.
Add tiny models (60–810 triangles, no bevels) and per-axis stretching (below) and you get
"blurry + no detail". Side effect: the colour override in `module3d.tsx:340-351` only touches
`MeshStandardMaterial`, so it silently does nothing on these unlit GLBs.
