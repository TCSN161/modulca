# docs/sessions: prompturile pentru sesiunea următoare

Fiecare sesiune scrie la final promptul pentru următoarea sesiune a chat-ului ei în `NEXT-{N}.md` (N = numărul chat-ului, ex. `NEXT-2.md`). Suprascrie fișierul, nu adaugă.

Format: prima linie = numele sesiunii propuse (`{N}.{NN}.{Eticheta}_{subiect}_{YYYYMMDD}`), apoi promptul complet. MAIN pornește sesiunea din acest fișier când îi vine rândul în [[MCA-DOC-ROADMAP-ALL-CHATS-2026-11-26]] §2.

Orice chat poate scrie DOAR propriul `NEXT-{N}.md` aici (excepție de la WORKFLOW §10).
